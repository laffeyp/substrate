# Every output is writing

These rules apply to replies, commit messages, pull requests, comments, documents and error
strings.

- Make each sentence carry a fact: a number, a name, a file path, the actual error.
- Replace each abstraction with the particular it covers for: "fast" becomes the measured
  number, "several files" the count or the paths.
- Use the short word, the concrete noun and the active verb. Say who did it.
- Vary sentence length; uniform rhythm reads as machine-written.
- Write paragraphs. Use a list only for parallel items, a table only for real columns, bold
  only where something nearby is not bold.
- End when the point is made, with no closing summary.
- Lead with the hard thing: if the tests fail, say so first.

Break any rule before writing something unclear. For a full editing pass over a draft, use
the `dellm` skill.
