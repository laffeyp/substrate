Street-team sticker/poster idea the user asked to keep: rendered in whatever design the substrate UI eventually adopts, with a QR code and ONE fake user review in quotes — roughly **"Fuck AI. But if we gotta use it, I'd rather use it in substrate."** Keep the voice grudging and profane, not cheery — the swear is the credibility.

**Taglines (lockup):** punchy line **"Substrate — you hate AI, but make it do cool shit anyway"** (the winner: second-person, grudging-skeptic, un-corporate), with the descriptor subtitle **"The cockpit for AI."** Visual: a Millennium-Falcon-style cockpit — the lived-in, "fastest hunk of junk in the galaxy" ship a real pilot trusts that pulls off the impossible run; the anti-slick-VC-SaaS spaceship. On-brand with the cockpit product framing and the 90s/2000s cool-tech-object aesthetic.

**Why:** it compresses the entire go-to-market into a joke. The reviewer is a skeptic (the target audience), it's openly anti-hype, adoption is grudging-but-real, and "use it *in* substrate" carries the cockpit framing (substrate = the surface you run the AI *through*). It is "for smart people, not hype people" as a sticker.

**How to apply:** guerrilla / street-team distribution asset. Pairs with the 90s/2000s "cool-tech-object" aesthetic direction and the skeptic-first, person-to-person diffusion strategy (show up with the fix, not the pitch). See [[substrate-cockpit-product-thesis]] for the broader positioning this is a shard of.
